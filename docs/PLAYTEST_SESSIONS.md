# Registro de sesiones de playtest

Plantilla para anotar sesiones reales del modo presencial. Todavía no hay sesiones cargadas. No se completan participantes, resultados ni observaciones por adelantado.

El protocolo, los escenarios y la severidad están en [PLAYTEST_PLAN.md](PLAYTEST_PLAN.md). Las fichas de problemas están en [PLAYTEST_FINDINGS.md](PLAYTEST_FINDINGS.md). Cada sesión usa un escenario de ese plan. Se copia el bloque de abajo y se pega al final de este archivo, con los campos que ocurrieron. Lo que no ocurrió se deja vacío.

No se anotan nombres, iniciales ni el texto o el número de una carta. El dispositivo se describe por modelo, no por quién lo usa. Si la pantalla no llega al reparto, a los votos o a una ronda, esos campos quedan vacíos.
