# Hallazgos de playtest

Fichas para problemas salidos de una sesión real. [PLAYTEST_SESSIONS.md](PLAYTEST_SESSIONS.md) no tiene sesiones y [PLAYTEST_EVALUATION.md](PLAYTEST_EVALUATION.md) no tiene consolidaciones. Por eso esta lista no trae hallazgos, participantes ni prioridades inventadas.

Cuando una sesión deje un problema, se copia la ficha y se pega en «Hallazgos». La acción correctiva se propone y no se implementa aquí. Una sugerencia de una persona queda como propuesta de mejora, no como requisito aprobado.

La severidad de esta ficha es crítica, alta, media o baja. Un hallazgo bloqueante de [PLAYTEST_PLAN.md](PLAYTEST_PLAN.md) se anota como crítico.

## Ficha

```text
Identificador:
Sesión:
Clase (defecto técnico, problema de experiencia, propuesta de mejora):
Severidad (crítica, alta, media, baja):
Módulos afectados:

Comportamiento observado:
Comportamiento esperado:
Pasos de reproducción:
Evidencia:

Acción correctiva propuesta:
```
